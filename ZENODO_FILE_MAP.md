# GitHub and Zenodo file map

## GitHub package

Contains source code, configuration, manifests, final reports, revision outputs, figures, and tables. It excludes trained run artifacts so every tracked file remains below GitHub's 100 MB limit.

## Zenodo package

The archive `bspc_binary_autofocus_benchmark_v1.0.0.tar.gz` adds the complete saved `runs/` tree and the locked prediction/calibration inputs used by the revision procedure. It preserves folder structure when extracted.

Neither package contains the raw microscopy images or the missing source manuscript `BSPC_binary_1_v1.docx`.
